# 界面风格

在设置页的「外观 → 界面风格」中选择「经典」或「液态玻璃」。默认使用经典，切换即时生效，重启后恢复选择。Debug 与 Release 分别保存自己的风格偏好。

两种风格共用三个页面、Pager、表单状态和业务处理。切换时保留当前标签、当前进程内的滚动位置与输入；进程重启后恢复上次标签，不额外保存页面滚动位置。

## 材质与组件

- 经典保留全宽底部导航和 Material 表单。
- 液态玻璃采用悬浮胶囊导航，左右留白 20dp，底部安全区上方留白 12dp，基础高度 64dp；标签使用图标及文字，选中背景随页面滑动。
- 玻璃模式使用连续的蓝紫与青色光场背景，混入系统动态强调色；流线为玻璃边缘提供可折射的背景层次。
- 底栏采用 Clear 透明材质、浅模糊、边缘折射与定向高光，滑动时选中胶囊同步移动；顶部使用同系列悬浮玻璃面。
- 卡片与按钮采样独立背景层，使用透明底色、折射、渐变亮边、浮起阴影和按压亮光。按钮以中性文字和轻染色为主，主题色仅作少量强调；输入框使用内嵌填充面，聚焦时提亮底色，不绘制粗主题色边框。
- 外层卡片使用 28dp 圆角、柔和高光与阴影；卡片内部的说明区只使用轻量衬底，避免叠加玻璃透镜。音色菜单与 BottomSheet 使用同系列玻璃表面及更高染色强度保证可读性；菜单为当前音色显示轻量选中底色与勾选标记。
- 经典模式保留原背景和渐变模糊。两种模式都跟随系统明暗模式与动态强调色。系统字体放大时标题、导航和按钮允许增高，键盘弹出时界面避让键盘。

## 实现约定

`data/UiStyle.kt` 定义稳定存储值 `classic`、`liquid_glass`，DataStore 键为 `ui_style`。未知值按经典展示，外观状态不进入 `TtsSettings`。

`ui/theme/UiAppearance.kt` 管理样式参数与 CompositionLocal；`ui/components` 管理共用控件、风格选择和玻璃导航。Pager 与输入状态始终位于风格分支之外。

使用同版本 Haze `2.0.1` 的 core、blur、glass 模块，Compose UI 和测试工具对齐到 `1.12.1`。Glass API 为实验性 API，升级时先检查经典模糊及玻璃材质。采样使用当前内容的 `HazeInput.Sources`，底栏采用固定 Balanced 配置；不启用实验性的 Android 原生窗口 Backdrop 后端。库在不支持完整光学效果的平台保留形状、染色和边缘高光，简化折射等效果。

`GlassSurface` 的表单采样源只包含 `GlassBackdrop`，避免采到自身、相邻卡片文字或嵌套表单。卡片和按钮关闭额外模糊及折射细节采样，保留基础折射和光照；顶部与底栏采样背景及滚动内容。背景不使用持续动画，Pager 的拖动偏移仍仅在选中胶囊绘制时读取。
