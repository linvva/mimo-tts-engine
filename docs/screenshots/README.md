# README 截图

图片来自当前源码的 Debug APK，在临时 Android 模拟器上截取，使用演示配置，不包含真实 API Key。HTTP 截图中的本地服务实际运行，未调用 MiMo 合成接口。

| 文件 | 场景 |
| --- | --- |
| `classic-tts.png` | 经典风格 TTS 页 |
| `glass-tts.png` | 液态玻璃风格 TTS 页 |
| `glass-http.png` | 玻璃风格 HTTP 页，本地服务运行中 |
| `glass-voices.png` | 玻璃音色菜单，选中“冰糖” |

四张图片统一使用浅色主题、手势导航、正常字体、1.0× 语速与 720 × 1600 分辨率。保留完整界面，仅缩放和优化 PNG，不修改界面内容。中英文 README 共用这些文件，更新界面后应同步重拍。
